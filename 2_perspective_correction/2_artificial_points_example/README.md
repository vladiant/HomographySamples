# Artificial Points Perspective Correction Example

This example follows the structure of `2_perspective_correction/1_example`, but instead of hard-coded measured image points it uses artificially generated correspondences.

What is generated:
- `objectPoints`: planar chessboard points generated by `calcChessboardCorners`.
- `corners1` and `corners2`: corresponding 2D points generated with `projectPoints` from two synthetic camera poses.

Then the code:
- estimates pose for each view with `solvePnP`,
- computes relative camera motion,
- builds and decomposes homography from camera displacement,
- estimates homography with `findHomography` and decomposes it for comparison.

## Folder

`2_perspective_correction/2_artificial_points_example`

## Build

```bash
cd 2_perspective_correction/2_artificial_points_example
cmake -S . -B build
cmake --build build
```

## Run

```bash
./build/artificial_points_example
```

## Tested Result

The example was built and executed successfully on 2026-11-14.

Observed runtime behavior:
- 54 synthetic object points were generated.
- Homography decomposition from camera displacement returned 4 solutions.
- Homography decomposition from `findHomography` also returned 4 solutions.
- As expected for homography decomposition, multiple mathematically valid solutions appear (sign/pose ambiguity), and one solution is close to the relative pose recovered from camera displacement.

This confirms the synthetic-point pipeline is working end-to-end and demonstrates the same decomposition characteristics as the measured-point example.
